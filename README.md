# Realistic Human Face Generation using DCGAN

## 📌 Project Overview

This project focuses on generating synthetic human face images using a Deep Convolutional Generative Adversarial Network (DCGAN).

The model is trained on the CelebA dataset and learns to generate new face images from random noise through an adversarial training process between two neural networks: the Generator and the Discriminator.

The project is implemented using PyTorch in a Kaggle Notebook environment.

## 🎯 Project Objectives

- Understand and implement Generative Adversarial Networks.
- Build a DCGAN architecture from scratch.
- Generate synthetic human face images.
- Compare generated images with real CelebA images.
- Evaluate the model using training loss curves and FID.
- Build an interactive interface for face generation.

## 📂 Dataset

**CelebA – Large-scale CelebFaces Attributes Dataset**

- Total Images: 202,599
- Image Type: RGB
- Training Resolution: 64 × 64
- Input Format: Three color channels

The dataset contains a large collection of celebrity face images with diverse facial attributes and appearances.

## 🧠 Model Architecture

The project uses a Deep Convolutional Generative Adversarial Network (DCGAN), consisting of two neural networks.

### 1. Generator

The Generator takes a random latent vector as input and transforms it into a synthetic face image.

- Input: Random noise vector
- Latent Dimension: 100
- Architecture: Transposed Convolutional Layers
- Activation: ReLU and Tanh
- Output: 64 × 64 RGB image

### 2. Discriminator

The Discriminator receives real or generated images and predicts whether an image is real or fake.

- Input: 64 × 64 RGB image
- Architecture: Convolutional Layers
- Activation: LeakyReLU and Sigmoid
- Output: Real/Fake probability

## 🔄 Training Process

The training process follows these steps:

1. Load and preprocess CelebA images.
2. Generate random noise vectors.
3. Generate synthetic images using the Generator.
4. Train the Discriminator on real and generated images.
5. Train the Generator to fool the Discriminator.
6. Track Generator and Discriminator losses.
7. Save generated samples and model checkpoints.

## 📊 Model Evaluation

The project uses several methods to evaluate the generated images.

### 1. Real vs. Generated Images

Visual comparison between real CelebA images and synthetic images generated by the model.

### 2. Training Loss Curves

Plotting Generator Loss and Discriminator Loss to monitor adversarial training behavior.

### 3. Fréchet Inception Distance (FID)

FID is used to measure the similarity between the distributions of real and generated images.

A lower FID score generally indicates better similarity between the generated and real image distributions.
